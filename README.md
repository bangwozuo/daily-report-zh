## 它是谁

面向 **本地生活商家** 的数字员工资产包。

| 项目 | 内容 |
|------|------|
| 目标用户 | 全部门店（受众最广） |
| 交付物 | 日报推送准时率 100%（每晚 22:00）；老板阅读耗时 ≤1 分钟；异常预警召回率 |
| 技能数 | 3 |
| 工作流数 | 4 |
| 旧名存档 | `门店经营日报分析师` |
