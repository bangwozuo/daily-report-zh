## 这是什么

`日报文案生成` 是一个**原子技能**资产。它不是一个软件，也不是一段代码，
而是**可以直接复制粘贴到任意 AI 工具里使用的提示词资产**。

| 特性 | 说明 |
|------|------|
| 零 API Key | 不需要任何密钥 |
| 零部署 | 没有服务端、没有脚本 |
| 平台无关 | Coze / WorkBuddy / Dify / Claude / ChatGPT 均可 |
| 用户自备算力 | 模型来自你自己的订阅 |

## 快速开始（3 步）

```text
1. 打开 skills/daily-report-copy/prompt.txt
2. 全文复制
3. 粘贴到你的 AI 工具，按输入规格提供数据
```

## 输入输出

| 项 | 内容 |
|----|------|
| 输入 | 当日（或区间）经营指标：营收 / 订单 / 访客 / 退款额，可选对比数据与特殊期 |
| 输出 | **一句话结论 + 三个关键数 + 一句提醒 + 一个行动建议**（正文 ≤ 200 字） |

派生指标（客单价 = 营收÷订单、转化率 = 订单÷访客、退款率 = 退款额÷营收）由公式重算，
**不接受用户直接给出的结论值**。

## 面向谁 / 解决什么

- **用户群体**：餐饮、零售、美业、休闲娱乐等线下门店的店主与店长
- **典型场景**：打烊后 1~2 分钟内、在手机上看完当天经营情况并决定明天先做什么
- **解决痛点**：数据表看不懂、结论没人提炼、每天要花 30 分钟自己算账
- **衡量指标**：日报可读性（能否读出方向与动作）、正文长度（≤ 200 字）、关键数数量（≤ 3 个）

详见 [用户群体](docs/07-audience.md) 与 [解决问题与价值](docs/08-value.md)。
