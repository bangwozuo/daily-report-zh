# 经营日报可编辑交付与证据表达模板

日报模板：一核心结论(≤40字)；二关键指标(最多3个，营收优先，其次退款率/转化率/客单价)；三趋势与异常证据；四明日排查(唯一动作≤60字，责任人/动作/范围)；五来源与边界。可复制正文≤200字，每个数字有同口径参照或明确缺失，最多一项提醒。输入只接受已核指标和确认记录，文案技能不自行重跑异常检测或口算新指标。同比缺失不写幅度，候选与确认分开；原因无证据只写待核。交付Word五章、Excel五页及JSON；实际源文件/SHA/期间/仿真标志、人工确认或退回理由均可追踪。外部使用先核对当前修订，打回文案回文案节点，不篡改原指标。
