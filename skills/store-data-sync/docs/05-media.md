## 操作清单

1. 登录企业微信管理后台或使用企业微信 API，获取客户列表（客户联系模块）。
2. 确认所需客户字段（如姓名、标签、添加时间），导出或接口读取。
3. 在企业应用中配置消息模板，编写通知文案。
4. 调用「发送应用消息」接口或群机器人 Webhook，向指定客户或客户群推送通知。
5. 记录发送日志，监控送达状态与失败重推。
