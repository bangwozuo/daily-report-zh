## 字段映射

| 业务字段 | 系统字段 | 方向 | 说明 |

| 通知内容 | msg_content | 写 | 通过企业微信应用消息或群机器人发送 |
| 接收对象 | to_user / to_party | 写 | 指定成员或部门 |

## 操作清单

1. 登录企业微信管理后台或使用企业微信 API，获取客户列表（客户联系模块）。
2. 确认所需客户字段（如姓名、标签、添加时间），导出或接口读取。
3. 在企业应用中配置消息模板，编写通知文案。
4. 调用「发送应用消息」接口或群机器人 Webhook，向指定客户或客户群推送通知。
5. 记录发送日志，监控送达状态与失败重推。

## 能力边界

本资产为纯提示词形态，**不能自动读写外部系统**。上述字段映射与操作清单仅为参考，实际执行需在用户的企业微信管理后台或自建应用中完成，并确保已开通「客户联系」与「应用消息」权限。
