## 四、T4 调度型要素验证

| 要素 | 落点 | 结果 |
|---|---|---|
| 时间轴 / 触发规则 | SKILL.md「只读接入 SOP」+ prompt.txt 每日 21:30 时间轴（6 步） | ✅ |
| 每步人工确认点 | SOP 表 🔒 列共 4 个人工确认点（收数/校验/脱敏/交付）+ 巡检/复盘 2 个 | ✅ |
| 只读连接器授权路径 | 官方 API（OAuth 授权范围内）/ 用户导出 / 手工录入 三档白名单 | ✅ |
| 授权到期处理 | `last_sync` 距今 > 24 小时且为官方 API → 标记「授权可能到期」，提醒责任人续期 | ✅ |
| 降级路径 | 有 API → 直连；无 API 有后台 → 用户导出；两者都无 → 公开榜单/行业报告估算（标注来源），**不做爬取** | ✅ |
| 合规红线 | 爬取 / 模拟登录 / 协议机器人 / 接码 = 禁止；六类个人信息不录入 | ✅ |

## 五、边界与依赖

- 依赖：`openpyxl` / `matplotlib`（由 `lib/assettools.py` 的 `at.need()` 统一检查）
- 缺依赖时脚本打印修复命令并以**退出码 2** 结束，不静默失败
- `sources` 为空时以**退出码 3** 结束并提示补齐接入配置
- **不连接任何外部系统**：无凭证、不登录后台、不调用平台 API、不访问网络

## 六、结论

本资产四件套齐全，prompt 深度达标（白名单/黑名单接入判定 + 最小字段集 + 降级路径 +
